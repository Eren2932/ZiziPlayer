# Как применить Zizi Desktop 0.3.5 preview

Это обновление исходников репозитория, НЕ установщик и НЕ готовый EXE. На GitHub автоматически ничего не отправлено.

## Применение

Сделай резервную копию текущего репозитория и %LOCALAPPDATA%/ZiziPlayer. Распакуй СОДЕРЖИМОЕ ZiziDesktop-0.3.5-repo-update.zip в корень репозитория с сохранением путей, а не загружай внешний ZIP одним файлом. При наличии собственных более свежих правок сначала сравни diff в docs/desktop.

Архив добавляет desktop/releases/ZiziDesktop-0.3.5-preview-source.zip и документацию, обновляет desktop/current.json и ci/check_desktop_source.py. Внутренний source ZIP вручную распаковывать в корень репозитория не нужно — его читает существующий CI-extractor. Старый 0.3.4 ZIP остаётся для отката. После применения desktop/current.json должен указывать 0.3.5-preview.

Закоммить изменения в отдельную ветку. Запусти существующий Actions → Build Zizi Desktop Windows preview (manual) для этой ветки. Оставь те же рабочие значения RESOLVER_URL, RESOLVER_TOKEN и allow_http / DESKTOP_ALLOW_HTTP, с которыми уже работает твой 0.3.4. Не раскрывай секреты в чате и не вставляй их в исходники.

## После сборки

Дождись успешной компиляции, тестов и упаковки. Скачай ZiziDesktop-Windows-x64-0.3.5-preview и распакуй всю app-image папку, не один EXE. FFmpeg/FFprobe остаются внешними; настройки пути сохранены. Не запускай две версии одновременно с одной библиотекой.

Проверь checklist REVIEW_0.3.5.md. Особенно: обложка при скролле туда/обратно, цветовой стык, рамка/resize/DPI, refresh при введённом без Enter запросе, пустом поле и активной загрузке, открытие наклонённых альбомных обложек.

Настройки → Оформление: панорамные шапки, движение фона, системная рамка. Системная рамка применяется после перезапуска и возвращает нативное оформление Windows, которое может быть светлым. Новые UI-настройки сохраняются отдельно в Java Preferences, медиатека не мигрирует.

Если Actions падает, сохрани ZiziDesktop-test-reports и desktop-build.txt. Не обходи тесты ради получения EXE: в the Computer полная Kotlin/Compose-сборка и Windows-рендер не выполнялись.

## Откат

Верни desktop/current.json и ci/check_desktop_source.py из предыдущего коммита и пересобери 0.3.4. Новый архив можно оставить: неактивные ZIP не используются. Формат библиотеки прежний; новые UI-предпочтения старой версией игнорируются.
