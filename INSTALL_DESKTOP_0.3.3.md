# Установка Desktop 0.3.3 preview

Это **пакет обновления исходников репозитория**, не готовый Windows EXE. Он подготовлен по public snapshot `1c8b4a4`, Desktop 0.3.2-preview. Не меняет Android ZIP, Android workflow, сервер, адрес/режим подключения, токены или формат локальных данных.

## Как применить

Сохрани старую рабочую сборку. Распакуй **содержимое** `ZiziDesktop-0.3.3-repo-update.zip` в корень репозитория с сохранением путей. Обновляются `desktop/current.json` и `ci/check_desktop_source.py`; добавляются новый `desktop/releases/ZiziDesktop-0.3.3-preview-source.zip` и документация. Не нужно распаковывать внутренний source ZIP в корень GitHub: его достаёт существующий `ci/extract_desktop.py`.

Важно: просто загрузить внешний ZIP одним файлом в GitHub недостаточно. Проверка: открыв `desktop/current.json` в репозитории, ты должен увидеть **0.3.3-preview**. Если после snapshot `1c8b4a4` были свои правки в этих файлах, сначала сравни, а не заменяй вслепую. Diff исходников находится в `docs/desktop/desktop-0.3.2-to-0.3.3.diff`.

Закоммить изменения в отдельную ветку. Затем запусти существующий workflow **Build Zizi Desktop Windows preview (manual)** через GitHub Actions. Сохрани прежние `RESOLVER_TOKEN`, `RESOLVER_URL` и тот же режим `allow_http`/`DESKTOP_ALLOW_HTTP`, на котором работала 0.3.2. Никакие секреты вводить в код или присылать в чат не нужно. В пакете нет замены workflow: текущий `.github/workflows/desktop.yml` уже подходит и выполняет тесты перед упаковкой.

После успешной сборки скачай **ZiziDesktop-Windows-x64-0.3.3-preview**. Распакуй всю папку app-image, а не один EXE. FFmpeg и соседний FFprobe остаются внешними; сохранённый путь работает как раньше. При необходимости: Настройки → О приложении → Диагностика и аудиодекодер.

Если сборка падает, скачай `ZiziDesktop-test-reports` и лог `desktop-build.txt`. Kotlin/Compose здесь не компилировались; статические проверки не гарантируют успешный CI. Не обходи тесты ради получения EXE.

## Первое включение

Не запускай старую и новую копии одновременно с одной папкой `%LOCALAPPDATA%/ZiziPlayer`. Резервная копия этой папки перед тестом желательна; формат данных сохранён, миграция не нужна.

Проверь медиатеку и плейлист, затем поиск от двух символов и сетевого исполнителя. Стрелка в заголовке левой панели сворачивает её до значков, верхняя иконка медиатеки скрывает полностью. Кнопка очереди — справа внизу плеера. Для файлов/папки/ссылки раскрой медиатеку и нажми `+`. Отдельных fake-подкастов или кнопок отсутствующих функций нет.

Проверь перезапуск, воспроизведение/паузу/перемотку и очередь; затем DPI/размеры окна по checklist в `docs/desktop/REVIEW_0.3.3.md`. Для окончательного визуального сравнения нужны скриншоты **уже новой сборки Zizi**: приложенные в задаче изображения — только Spotify-референсы.
