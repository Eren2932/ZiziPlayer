# ZiziPlayer 7.9.1 (сервер без изменений: 1.35-canvas3)

Фикс только тестов. Деплой 7.9.0 остановился на `test_canvas_135.py`: 3 теста (`Pipeline`) падали с
`TypeError: expected string or bytes-like object` в `canvas()` на `_DZ.match(dz)`.

**Причина.** Тесты вызывали эндпоинт напрямую, без части параметров. В настоящем FastAPI неуказанный параметр
при прямом вызове — объект `Query(...)`, а не его default (при HTTP-запросе FastAPI подставляет значения сам, поэтому
боевой код не затронут). Моя заглушка в песочнице возвращала default, так что локально тесты проходили.

**Исправление.** В тесте добавлен хелпер `ask()`, который передаёт все параметры явно. Заглушка fastapi в песочнице
теперь ведёт себя как настоящая и воспроизводит падение. `zizi_canvas.py` и пломба не менялись.

Проверено: test_canvas_133 (8), 134 (10), 135 (14), test_server_deploy (55) — OK.
