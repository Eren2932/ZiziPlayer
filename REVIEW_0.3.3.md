# Разбор референсов и изменений Desktop 0.3.3

## Что изучено

Получен свежий public GitHub snapshot `1c8b4a4`. Изучены `desktop/current.json`, последний source ZIP 0.3.2, install/review 0.3.2, handoff 0.3.0, mobile 6.39.9 changelog, настольные UI/state/palette, модели треков/каталога, сохранение библиотеки, очередь, CI и общие файлы. Из мобильного ZIP повторно прочитаны страница коллекции и релевантные части поиска; всю мобильную кодовую базу заново не аудировали.

Все девять скриншотов — только референсы Spotify, не скриншоты текущего Zizi. Исходные изображения имеют **1920×1080**; отображённые в чате уменьшенные копии — **1538×865**. Сравнивать их пиксельные координаты напрямую с Compose dp без знания DPI некорректно. Windows DPI, системная рамка и шрифт также влияют на результат.

На оригинальном 1622 нижний спокойный срез y=900 показывает левую панель x=7…426 и основной контент x=435…1860; реальная базовая поверхность Spotify — RGB(18,18,18). На 1625 при сворачивании левая рейка — x=7…78, контент начинается x=87. На 1630 правая очередь отделяется от главной области, заканчивающейся x=1484. В Zizi сохранены свои базовые цвета #101010/#1B1B1B, чёрная оболочка и бренд #F97316, а не чужой зелёный.

## Принципы реализации

Поиск и нижний плеер привязаны к ширине **всего окна**, а не оставшегося контента. Поэтому при открытии очереди центр поиска не скачет. Параметры `DesktopLayout.java` проверяются на JVM: поиск до 480 dp, шапка 60 dp, плеер 90 dp; боковая колонка 300/64/0 dp; правая — 330 dp или 280 dp на узких окнах. В сравнении с референсом намеренно не заявлено равенство каждого px: нет фактического рендера Zizi для наложения изображений.

Градиент принадлежит карточке открытого исполнителя/коллекции. Семплирование — прежнее мобильное ядро по видимому квадрату 64×64. Изображение читается и декодируется вне UI-потока; один и тот же `CoverData` содержит картинку, мобильную палитру и primary. Дополнительных HTTP-запросов специально ради градиента нет. Ограниченные RAM/disk caches и semaphore(3) сохранены; 32 фиксированных замка объединяют конкурентные cache misses одинаковой обложки. Ключ эффекта теперь включает artwork URL.

Палитра шапки ограничена по Oklch: L 0.36…0.50, C ≤ 0.15, оттенок сохраняется с уменьшением насыщенности вне gamut. Переход 380 мс прерывается из текущего видимого цвета. Один вертикальный градиент включает и hero, и действия; нижняя точка равна базовой панели. Белый текст не меняется на цвет обложки. При отключении настройки/нет обложки фон нейтральный. Широкие градиенты по-прежнему требуют проверки на конкретном дисплее: отсутствие banding не гарантируется; размытия и шумовой текстуры нет.

В поиске отдельный `SearchPreview` управляет debounce, поколением запроса и отменой. Треки ограничены шестью уникальными ID; список подсказок берётся из реальной истории и метаданных, без придуманных запросов. Сохраняется только явно отправленный поиск. Сетевые вызовы остаются в существующем клиенте. Ошибка всплывающего поиска не ломает проигрывание; локальные совпадения остаются доступны. Это не новый серверный autocomplete endpoint.

При редактировании громкости коллекции больше не пересобираются только из-за изменения settings. Таблица треков не подписана на таймер позиции; прогресс наблюдается внутри транспорта. Колонки ленивые; scrollbar использует тот же LazyListState. Независимые выезжающие очередь/DSP заменены одним контейнером, чтобы при переключении анимации не вычитали обе ширины одновременно.

## Что не делалось

Нет переноса подкастов/видеофункций только ради изображения CreepCast/Gobcast. Нет Spotify-шрифта и брендинга, новых подписок, фиктивных счётчиков/дат/альбомов, новых серверных контрактов, новых сторонних зависимостей, миграции данных или изменения аудиотракта. Центральный плеер в минимальном окне сохраняет основные действия; часть дополнительных кнопок в правой зоне показывается только при достаточной ширине. Полный пиксельный паритет, плавность на Windows и фактический FPS не измерялись.

## Приёмка после Actions

Проверить при 100%, 125%, 150% DPI, минимум 960×680 логических размеров; далее 1280×800, 1440×900 и максимально развёрнутое окно. Важно сравнивать рабочую область, исключив Windows taskbar/системную рамку. Снять экраны медиатеки, локального плейлиста, сетевого исполнителя, альбома, popup поиска, очереди и прокрученной коллекции.

Для поиска: быстрый ввод/стирание, запрос → другой запрос при медленной сети, пустая строка, offline, 401/404/429, Escape, клик снаружи, стрелки/Enter, сохранение без запуска и воспроизведение трека. Убедиться, что поздний ответ не подменяет новый и частичные строки не попадают в историю.

Для цвета: красная/синяя/монохромная обложка и отсутствие изображения; быстро открывать разные страницы; сменить играющую музыку при открытой странице другого исполнителя. Цвет страницы не должен следовать плееру. Проверить переключатель оформления, полосу перехода у действий, читаемость длинных названий и закреплённый заголовок.

Для очереди/плеера: открытие/закрытие, очередь ↔ DSP, скрытая/свёрнутая левая панель, перенос и удаление из очереди, shuffle с честной подписью, pause/seek/next при воспроизведении, в паузе и при загрузке. Проверить совпадение длительности/позиции с выбранным треком, восстановление библиотеки и очереди после закрытия. Изначальные аудиотесты CI должны пройти без исключений.
