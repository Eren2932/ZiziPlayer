# ZiziPlayer 6.84.0-rc1 — результат

Полный мобильный исходник на базе 6.83.0-rc4. `versionCode = 176`: существующий GitHub workflow подхватит новый ZIP в корне репозитория.

Карточка повторяет измеренную геометрию последнего присланного изображения: пять портретов, центрированные тексты, маленькая белая кнопка «Выбрать» и крестик. Выбор артистов полноэкранный, с оранжевым контуром Zizi, отдельным поиском и вставкой настоящих похожих артистов в порядке нажатий.

Гость и пользователь с аккаунтом видят карточку до первого успешного завершения. Нужны минимум три разных ID. Закрытие, «Позже», ошибки и частичные ответы не отмечаются как успех. Завершение сохраняется только после живых рекомендаций для подтверждённого набора и записи зашифрованного снимка. Подтверждённый выбор переживает перезапуск процесса.

## Проверки

Полный `python tools/check_selftest.py`: **PASS**, exit 0, **956 исполнений Python-тестов**. Новый production-Java тест: **64 219 утверждений**, 6000 случайных сеток. Добавлены 13 Android-сценариев и подключены к API 28/35 в существующем CI.

**Android/Gradle-сборка, APK-отрисовка, device-тесты и живой сервер здесь не запускались.** Серверная логика и аудиоплеер не менялись. Подробный handoff, математические размеры, полный лог и перечень изменений находятся внутри ZIP.

## Важно для сервера

Корневой `ZiziServer-1.15-browse-fix.zip` не поддерживает `s2`. Если ещё используется именно он, выбирай 3–8 исполнителей; для большего набора нужен серверный комплект 1.16 из мобильной базы либо совместимый модуль. Фактическая версия развёрнутого сервера неизвестна — ложный успех при потерянных ID не показывается.

Коллаж вырезан из предоставленного референса. Перед публичным распространением нужно проверить права на сторонние портреты либо заменить PNG разрешённым изображением того же размера; логика и геометрия от этого не зависят.
