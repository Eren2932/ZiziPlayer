# ZiziPlayer 6.60.1 — исправления шапки и кнопок подборок

**Полный ZIP исходников Android, versionCode 113. Не APK.**
База: `ZiziPlayer-v6.60.0.zip` (112) из публичного `Eren2932/ZiziPlayer`,
зафиксированного на commit `aff86c06bba9d67a4c2cf1a51fee26d8083004ae`.
Дата работы: 15.09.2026. GitHub из этого диалога не изменялся.

## Исправлено

В `PinnedCollectionScaffold` фон баннера, его заголовок и троеточие теперь используют
одну прозрачность `bannerAlpha`, рассчитанную по фактической прокрутке. При нулевой
прозрачности кнопки меню нет в композиции — она не висит над обложкой и не оставляет
невидимый обработчик нажатия. При появлении панели меню проявляется синхронно с ней;
нажатие и семантика TalkBack включаются после полного появления. При возврате наверх
кнопка исчезает. Геометрия в `remember` учитывает изменение измеренной высоты и дистанции
закрепления. В режиме выделения по-прежнему показывается панель выделения.

Поле «Поиск в подборке» удалено из общего экрана локальных коллекций: плейлистов,
папок, избранного и всех треков. В домашних миксах и сетевых альбомах/плейлистах поля
уже не было — оно не добавляется. Сортировка сохранена отдельной кнопкой среди левых
действий; скачивание и импорт сохранены. Существующая навигация сбрасывает query и
searchOpen при открытии этих коллекций; логика ViewModel не изменялась.

Общий `CollectionActionsRow` ставит перемешивание непосредственно слева от круглой
Play/Pause. Он подключён к локальным коллекциям, домашним миксам и сетевым коллекциям.
У обеих кнопок одинаковая область нажатия 48×48 dp, центры по вертикали совпадают,
между центрами по горизонтали 48 dp. Правый отступ — 20 dp. Play остаётся единственным
экземпляром, при прокрутке закрепляется как прежде. Перемешивание уходит с шапкой;
в закреплённую панель дополнительная кнопка не добавляется.

Левые действия могут переноситься на следующую строку при крупном шрифте или узком
экране. Перемешивание выровнено по низу этой области, а позиция Play рассчитывается
от измеренного низа шапки — увеличение высоты левых действий не раздвигает центры
правой пары. На пустой подборке перемешивание недоступно. Поведение запуска очереди,
её sourceId, паузы и сетевого onShuffle сохранено.

## Геометрия референса

Измерен оригинальный файл `Screenshot_20260915_224200.jpg`, 1080×2400, а не уменьшенное
превью чата. Пороговая маска зелёного даёт круг примерно 139×139 px, x=884..1022,
правый свободный край около 57 px. Стрелки перемешивания занимают около 64 px по ширине;
центры правых кнопок разнесены примерно на 143.5 px. Антиалиасинг даёт погрешность границ.

Нормализация к ширине 360 dp даёт круг 46.33 dp, край 19 dp и межцентровое расстояние
47.83 dp. Использованы практические значения 48/20/48 dp, чтобы не уменьшать touch target
ниже 48 dp. Существующий ZiziIcons.Shuffle занимает около 18 из 24 единиц своего viewport:
холст 28 dp даёт видимую ширину стрелок около 21 dp, близкую к 64/3 dp на референсе.

Это воспроизведение размера и расположения с округлением и сохранением доступности,
не заявление о пиксельном совпадении на любом устройстве: скриншот не задаёт Android density.
Цвет остаётся фирменным оранжевым, иконки — существующие. Premium, совместный доступ,
кнопка добавления участников и другие отсутствующие функции из референса не добавлены.

## Область изменений

Основная логика правок находится в пяти файлах: `CollectionGeometry.java`,
`PinnedCollectionScaffold.kt`, `UnifiedLocalCollectionScreen.kt`, `HomeCollectionScreen.kt`,
`RemoteCollectionScreen.kt`. В `app/build.gradle.kts` изменены только версия и versionCode.
Дополнены тесты, preflight и документация; в прежних контрактных тестах обновлены
ожидаемые версия/код, без удаления проверок поведения.

Звуковой тракт Media3, Room, DataStore, сетевой каталог, сервер аккаунтов и облачная
синхронизация не изменялись. Нет новых зависимостей, разрешений или миграций.
Страницы исполнителей, общий поиск приложения, главный экран и полноэкранный плеер
не переделывались. В старой ветке локального исполнителя его поле поиска сохранено:
это не общий экран плейлистов/миксов.

## Применение

Загрузить **только `ZiziPlayer-v6.60.1.zip`** в корень `main` существующего репозитория,
не распаковывая. Штатный workflow выбирает полный мобильный ZIP по versionCode:
113 выше 112. Desktop, корневые `current.json` и workflow менять не нужно.
Копия workflow внутри ZIP сама по себе не запускается.

Обязательная проверка в среде с Android SDK:

````bash
gradle --no-daemon :app:testDebugUnitTest :app:compileDebugAndroidTestKotlin --stacktrace
gradle --no-daemon :app:assembleRelease --stacktrace
# При подключённом устройстве или запущенном эмуляторе:
gradle --no-daemon :app:connectedDebugAndroidTest --stacktrace
````

Проверить на телефоне раскрытую шапку, промежуточное проявление баннера, полный скролл
и возврат наверх; троеточие должно работать только на появившейся панели. Проверить
0/1/2/50 треков, длинный заголовок, 320/360/411 dp и шрифт ×2; сортировку, импорт,
скачивание, перемешивание, Play/Pause и режим выделения. Не должно быть поиска или
пустого места от прежнего редактора в плейлистах и общих подборках.

Перед установкой сохранить резервную копию библиотеки. Устанавливать APK поверх
текущего приложения с тем же ключом подписи; не удалять приложение ради обхода
несовпадения подписи. Успешные локальные проверки не являются гарантией сборки APK.
