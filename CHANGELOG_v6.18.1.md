# ZiziPlayer 6.18.1

versionCode 34 · versionName 6.18.1 · база v5 (миграции нет, ставится поверх 6.18.0/6.17.0)

Хотфикс одной строки: 6.18.0 не собралась.

## Что упало

```
e: .../ui/components/ZiziIcons.kt:45:13 Unresolved reference 'path'
> Task :app:compileReleaseKotlin FAILED
```

`path { }` внутри `ImageVector.Builder` — не метод билдера, а top-level extension
`androidx.compose.ui.graphics.vector.path`. Без явного импорта имя не резолвится; в файле были
импортированы `ImageVector` и `PathBuilder`, а сама DSL-функция — нет. Никакой другой ошибки
компиляции в логе нет: ресурсы, KSP и остальные 46 файлов прошли.

## Что сделано

* `ZiziIcons.kt`: добавлен `import androidx.compose.ui.graphics.vector.path`.
* `ZiziIcons.stroked(...)`: `pathBuilder = pathBuilder` заменено на трейлинг-лямбду
  `) { pathBuilder() }`. `path` объявлена `inline`, и передача туда сохранённого функционального
  значения вместо литерала — лишний риск на ровном месте; лямбда-литерал компилятор глотает всегда.
* Версия поднята до 6.18.1 / 34, чтобы не перевыпускать занятый тег v6.18.0.

Функционально к 6.18.0 не добавлено ничего: геометрия иконок, анимации выбора и правки ревью — те же.

## Правило на будущее

В Compose половина «методов» — top-level extension-функции (`path`, `group`, `drawCircle` в
`DrawScope` — член, а `Modifier.*` — extension). Новый файл с DSL-конструктором проверяем не по
«есть ли такой метод», а по строке импорта на каждое имя, которое пишется без точки-получателя.

# Вход в множественный выбор: убрано дёрганье кружков

В 6.18.0 я закрыл прыжки раскладки (шапка, фильтры, ширина правого слота), но сам переход остался
дорогим и геометрически кривым. По жалобе «дёргаются кружки» нашлось три причины, все три сняты.

## 1. Кружок стоял не там, где «⋮»

Слот был 74 dp, кружок центрировался по всему слоту (37 dp от края), а «⋮» стоит в 55 dp. Два
разных рисунка перекрёстно затухали в РАЗНЫХ точках — глаз читает это как рывок вбок на 18 dp,
хотя ни один узел не двигался. Видно и на скриншоте: кружок висит ровно между «сердцем» и «⋮».

Теперь слот — ровно 38 + 34 = 72 dp (сумма кнопок), а кружок живёт в такой же коробке 34 dp,
прижатой к правому краю. Его центр совпадает с центром «⋮» до пикселя: содержимое подменяется
строго на месте.

## 2. По Crossfade на КАЖДУЮ строку

Двенадцать видимых строк — это было двенадцать переходов, у каждого два живых поддерева на 190 мс
и по три анимации внутри (цвет фона, цвет галочки, масштаб). Всё это заводилось в одном кадре,
сразу после долгого нажатия, поверх сворачивания ряда фильтров, которое само по себе перемеряет
список каждый кадр. Кадры не укладывались в 16 мс — отсюда дёрганье.

Стало: **одна** анимация `pick` на весь список, поднятая в `TrackList`. Оба состояния правого
слота лежат в раскладке всегда и никогда не пересобираются, меняется только альфа их слоёв через
`graphicsLayer { alpha = pick.value }`. Чтение состояния уходит на фазу отрисовки слоя, поэтому за
все 190 мс перехода в списке **не происходит ни одной рекомпозиции** — ни одной на строку, ни одной
на кадр. Вход в выбор стоит один проход разметки, дальше едет композитор.

## 3. Подмена иконки посреди анимации

`RadioButtonUnchecked` → `CheckCircle` — два разных вектора, подмена мгновенная, и происходила она
в начале анимации масштаба. Читается не как «галочка щёлкнула», а как «иконка прыгнула».

Теперь кружок — один `Canvas` (`SelectDot`): кольцо гаснет, диск проявляется и подрастает с 0.9 до
1, галочка прочерчивается двумя линиями с круглыми торцами — всё одним числом `mark`, в фазе
отрисовки. Точки галочки заданы в долях радиуса, поэтому рисунок не разъезжается ни при каком
размере. Узлов на строку стало меньше, чем было: один Canvas вместо Box + Icon + два слоя Crossfade.

## Заодно

* Подсветка выбранной строки больше не идёт через `animateColorAsState` в композиции, а рисуется
  в `drawBehind` тем же числом `mark`: строка не рекомпозится 11 кадров подряд ради заливки фона.
* В режиме выбора весь правый слот — одна мишень «переключить», перекрывающая невидимые «сердце»
  и «⋮». Раньше по ним можно было попасть пальцем сквозь нулевую альфу и словить чужое действие.
* Анимация строки заводится только когда меняется ЕЁ галочка, а не при входе в режим.
