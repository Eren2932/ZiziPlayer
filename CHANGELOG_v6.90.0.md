## 6.90.0 — 2026-10-15

Перестройка хаба «Поиск»: вкус из каталога вместо медиатеки, гибридная витрина, тихое обновление без кнопки. База 6.89.10.

- **«Открой новое для себя» больше не зависит от локальных файлов.** Раньше карточки строились из тегов исполнителя локальных треков
  (`seeds` в `MainActivity`): «Неизвестный артист», имена из почты и т. п. становились карточками, а сама полка появлялась только при доступе к медиа.
  Теперь карточка — артист каталога (id Deezer + портрет). Личные берутся из ленты Главной (`HubTasteReader`: она уже чистит мусор и «не нравится»),
  остальное добирается публичной выдачей `/reco/onboard`. Карточка открывает страницу артиста и показывает собственный портрет и жанр
  (раньше — поиск «<имя> radio» и случайная обложка из пула хаба). Уже выбранные при знакомстве и «не нравится» не показываются.
- **Артисты меняются при каждом заходе.** `HubDiscoverPolicy.pick`: сначала невиданные за последние 120 показов, затем самые давние; жанры чередуются.
  Когда невиданные кончаются, пул расширяется графом похожих (`/reco/onboard?a=`). Нижняя полка «Артисты» тоже ротируется (раньше — статичный чарт).
- **Подборки — только гибрид.** Раньше при сбое Deezer загрузчик хаба молча переходил на сырой Innertube, и полки YouTube Music оседали в кэше под ключом гибрида.
  Теперь хаб опрашивает только `mix`/`dz`, `HubContent.hybrid` не пускает `yt` ни из сети, ни из кэша, `HubCache.VERSION` = 3 (старые кэши игнорируются).
- **Тематические полки.** К чарту добавляются 3 тематические полки за раз из 16 («Чилл», «Тренировка», «Русский рэп»…), каждый раз другие:
  поиск плейлистов, из которого остаются только редакторские (владелец — Deezer и редакции лейблов), не меньше 4 штук, иначе полки нет.
- **Обновление в фоне без кнопки.** Кнопка обновления в шапке удалена. При каждом заходе во вкладку (и возврате в приложение) `SearchViewModel.hubEntered()`
  сначала выкладывает подготовленное в прошлый раз, затем в фоне готовит следующее. Ни крутилки, ни сообщений, ни подмены списка под пальцем;
  сеть не чаще раза в 3 минуты. Кэш старше 3 часов заменяется сразу. «Повторить» при ошибке остаётся.
- «Твоя волна» строится вокруг артиста-якоря из Главной, а не вокруг самого слушаемого локального тега.
- Тесты: `HubDiscover6900Checks` (273 проверки реального Java-кода), `HubDiscoverShelves6900Test`, `HubContentTest`, `tools/test_hub_6900.py`.
- Сервер не менялся. Kotlin-часть не собиралась в среде разработки: проверьте `:app:compileDebugKotlin`.
