# ZiziPlayer 6.59.0 — поиск и сохранение библиотеки

Подготовлены исходники мобильной версии. `versionName = "6.59.0"`, `versionCode = 110`.
Основа: `ZiziPlayer-v6.58.0-recovered.zip`, мобильная версия 6.58.0 / 109,
из коммита `b9a60273fcdffde9b021d934dada98d72d681b2a` публичного репозитория Eren2932/ZiziPlayer.
Корневой `current.json` относится к Desktop: он не изменён. Серверы, протокол копии и схема Room не изменены.

## Поиск

Раньше вся шапка стояла вне LazyColumn с постоянной высотой. Теперь общий nested-scroll соединяет
измеряемую шапку со списком. При движении вниз по содержимому сначала сворачиваются заголовок
и строка «Популярно сейчас», затем оставшееся расстояние получает список. При возвращении
раскрытие получает только расстояние, которое список уже не может использовать у своего начала.
Дельты fling также проходят через тот же расчёт, без отдельной анимации по таймеру.

При доле сворачивания `f` высота цветной области равна:

````text
H(f) = statusInset + 9dp + round(titleHeight × (1 − f))
       + entryHeight + round(sectionHeight × (1 − f))
0 ≤ f ≤ 1
H(1) = statusInset + 9dp + entryHeight
H(0) = statusInset + 9dp + titleHeight + entryHeight + sectionHeight
````

Высоты titleHeight, entryHeight и sectionHeight получаются из измерения Compose, а не из
размеров скриншота. При обычном шрифте titleHeight = 68dp, sectionHeight = 44dp,
entryHeight ≥ 51.5dp. Системный отступ поступает из WindowInsets.statusBars.
Округление каждой сворачиваемой части — до физического пикселя. В промежуточных состояниях
суммарное отклонение от непрерывной формулы не превышает одного пикселя; крайние положения точны.

Низ фона в свёрнутом состоянии совпадает с низом поля. Верхний отступ 9dp сохранён.
Закрытые элементы не размещаются, а их семантика скрывается при полном сворачивании.
Сохраняется доля сворачивания, поэтому изменение плотности не оставляет старую пиксельную высоту.
Переход «все жанры» учитывает свёрнутую шапку. Раскрытие при простом движении назад посреди списка
не выполняется: полная шапка возвращается именно при достижении начала списка.

## Сохранение библиотеки

Вместо сплошного текста: карточка аккаунта с аватаром и адресом, состояние облака и дата последней
подтверждённой копии, основное действие, состав библиотеки на телефоне и предпросмотр облака.
Счётчики рассчитываются из фактического снимка: сохранённые треки, избранное, плейлисты.
Обложки и подписи — ограниченная выборка записей, включая избранное и плейлисты, не выдуманные примеры.
Большие числа показаны вертикальными строками, а не тремя узкими колонками.
Импорт/экспорт и подробные ограничения раскрываются отдельно.

Предпросмотр использует только HTTPS-обложки. Если сетевое изображение недоступно, остаётся
штатная заглушка с настоящим названием записи. Локальные изображения не выдаются за перенесённые:
текущий формат хранит ссылки/метаданные, а не файлы картинок. Профиль и аватар аккаунта сохраняются
отдельным сервисом профиля и в JSON библиотеки не включены. Аудиофайлы в копию не входят.

Перед импортом выполняются ограничения размера, проверка формата, схемы и полей без записи в базу.
Диалог показывает состав выбранной копии и прямо предупреждает о замене, а не объединении.
Для облачного восстановления зафиксирован hash показанного снимка: если сервер вернул другой,
восстановление останавливается с конфликтом. Существующая транзакция и страховочная копия перед
удалением строк сохранены. Защита папок не обходится. Экран также получил границу обработки касаний,
чтобы пустые участки не передавали нажатия в лежащие ниже экраны.

Ошибки не скрываются в техническом разделе. Отсутствие новых изменений при ручном сохранении
не выдаётся за новое подтверждение сервера: пользователь видит дату ранее подтверждённой копии.

## Строка состояния

Причина слияния: в MainActivity вызов StatusBarTint был внутри условия
`mounted && !eqOpen && !profileEdit`, то есть зависел от смонтированного плеера.
Теперь один вызов находится последним слоем внешнего Box окна, после приложения,
авторизации и окна библиотеки. Существующая чёрная вуаль 24% и системная высота сохранены.
Слой не принимает касания. Второй вызов внутри ZiziApp удалён, двойного затемнения от него нет.
Это общий путь для медиатеки, поиска, главной, плеера, эквалайзера, профиля, авторизации и сохранения.
Отдельные Android Dialog/ModalBottomSheet используют собственные окна и требуют проверки на устройстве.

Старые текстовые контракты обновлены для нового номера версии, коротких предупреждений и общего,
а не зависящего от плеера, расположения StatusBarTint; проверки безопасности сохранены.

## Как собрать

Загрузить `ZiziPlayer-v6.59.0.zip` **в корень существующего репозитория**, не распаковывая поверх Desktop.
Действующий корневой `.github/workflows/build.yml` проверен: он реагирует на `ZiziPlayer-v*.zip`
и выбирает проект по максимальному versionCode. Новый 110 выше исходного 109.
`current.json`, `desktop/`, секреты и корневой workflow менять не требуется.

Workflow сначала компилирует Kotlin и androidTest и запускает JVM-тесты, затем собирает APK.
Этот архив — исходники, а не APK. Локальная полная сборка не выполнена: в the Computer нет готового
Android SDK и Gradle; дополнительные зависимости не устанавливались. Успех GitHub Actions пока не проверен.

Перед проверкой восстановления экспортировать свою текущую библиотеку в отдельный файл.
Проверить на устройстве обычный/крупный шрифт, медленный свайп, быстрый fling, возврат к началу,
переключение вкладок, открытие/закрытие плеера, клавиатуру и изменение ориентации.
Для облака — гость, вошедший аккаунт, офлайн, пустая копия, конфликт двух устройств,
невалидный файл, отмена диалога и защищённые папки. Восстановление сначала проверять на тестовой библиотеке.

Изменения в удалённый репозиторий не отправлялись, серверные данные пользователя не затрагивались.
