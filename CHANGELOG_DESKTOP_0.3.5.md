# Desktop 0.3.5 preview

Обновление исходников на базе 0.3.4. Полная компиляция Compose и Windows-приёмка ещё необходимы.

## Шапки и прокрутка

Страница исполнителя получила панорамный фон вместо обязательного круглого портрета. Широкие изображения используются напрямую; квадратные вписываются в мягкое фотографическое окружение. Отдельный high-resolution tier до 1600 px, общий оригинальный disk cache и ограничение memory LRU по объёму пикселей. Подготовка изображений — на IO, не при прокрутке.

Общий CollectionViewport для каталога и локальных коллекций. Фото движется медленнее текста и плавно уходит в тень, обратный скролл восстанавливает его по той же кривой. Устранены резкий обрыв при удалении первого lazy item и 1dp цветовой скачок. Верхняя тень добавлена общим спискам. Для локального исполнителя обложка трека не названа его фотографией.

## Окно и настройки

Чёрный caption с кнопками и draggable area вместо белой системной полосы. Есть возврат системной рамки после перезапуска; полное нативное Snap-поведение не заявлено. Оформление, панорамы и движение настраиваются; добавлены разделы, поиск и переход к аудиоустройствам. Отдельное сохранение UI-настроек без миграции медиатеки. Уведомления больше не сдвигают шапку.

## Поиск

Убраны лишние стартовые пояснения. 24 жанра/настроения вместо 8; до двух реальных album search обложек на плитке, с наклоном и тенью. Обложка открывает конкретный альбом, название темы — поиск. Ограниченная параллельность, кэш, отмена и backoff. Это витрина существующего каталога, не новый персональный рекомендательный сервер.

Refresh теперь работает по тексту видимой строки поиска; при пустом поле обновляет витрину. Нажатие во время поиска перезапускает запрос, а не игнорируется.

## Проверки

88 source contracts, Kotlin/KTS delimiter check, 9 Python connection tests, численные модели цвета/прокрутки, hash-проверки критичных файлов и ZIP прошли. Добавлены 22 Kotlin/JUnit tests, здесь не запускались. Android, server, аудиодвижок, библиотечный формат, зависимости и workflows сохранены. ZIP содержит исходники для CI, не проверенный Windows EXE.
