# ZiziPlayer 6.14.0 (versionCode 29)

Версия починочная: `6.13.0-rc1` не собирался вообще — `:app:compileReleaseKotlin` падал на двух
неразрешённых ссылках. APK из rc1 не существует, так что 6.14.0 — первая живая сборка с правилом
«строка показывает состояние, кнопка показывает действие».

## Сборка — исправлено

Обе ошибки — отсутствующие импорты, ровно то, что показал лог CI:

| Файл | Ошибка | Причина | Исправление |
|---|---|---|---|
| `ui/components/Common.kt:451` | `Unresolved reference 'LocalPalette'` | новый `NowPlayingBadge` читает палитру, а в файле не было `import app.ziziplayer.ui.theme.LocalPalette` — до 6.13 палитра в `Common.kt` не требовалась | импорт добавлен |
| `ui/screens/SearchScreen.kt:688` | `Unresolved reference 'NowPlayingBadge'` | `Common.kt` лежит в пакете `ui.components`, `SearchScreen.kt` — в `ui.screens`, и импортирует компоненты поимённо, без `*` | добавлен `import app.ziziplayer.ui.components.NowPlayingBadge` |

Ни одна из ошибок не касалась логики: код 6.13 верный, он просто не компилировался. Ничего, кроме
импортов, для зелёной сборки менять не понадобилось.

## Маркер «сейчас играет» — теперь действительно один

В rc1 `NowPlayingBadge` был объявлен и подключён только в поиске, а медиатека и очередь продолжали
рисовать свои копии того же маркера — свой затемняющий `Box` плюс свой `EqualizerBars`. Правило
жило в трёх местах, и один раз оно там уже разъехалось — именно так и появился баг 6.13.

* `LibraryScreen.TrackRow` и лист очереди (`Sheets.kt`) переведены на `NowPlayingBadge`;
* у компонента появился параметр `barSize` (по умолчанию `size * 0.42f`) — медиатека и очередь
  передают прежние `17.dp`, поэтому строки визуально не изменились;
* затемнение сведено к одному значению `alpha = 0.46f` (было 0.45 в поиске и 0.48 в двух других
  местах — разница на глаз неразличима, зато значение теперь одно);
* прямых вызовов `EqualizerBars` за пределами `Common.kt` больше нет: следующий, кто захочет
  поменять маркер, физически не сможет поменять его в одном списке из трёх.

## Что не тронуто

* Формат обмена `share/PlaylistShare.kt` — байт в байт как в rc1, он ещё не разошёлся по чужим
  телефонам и остаётся открытым для правок.
* UI импорта (`FileProvider`, `intent-filter`, экран предпросмотра), `/playlist` с короткими
  кодами, рейт-лимит по IP, ETag на витрину — по-прежнему следующая посылка вместе с сервером 1.4.
* `http-cache` / `ETag` на сервере — единственный незакрытый пункт из списка тестировщика,
  он серверный и в APK не решается.
* Room остаётся на версии 4, миграций нет. `ZiziResolve 1.3` не тронут.

## Проверено перед отправкой

Компилятора Android в песочнице нет, поэтому имена проектных символов проверены статически:
для каждого `.kt` собраны объявления по пакетам и сверены с импортами файла (с учётом
`import пакет.*`). Кроме двух ссылок из лога, ни одного проектного символа без импорта не
осталось — включая три файла, которые правились в этой версии.
