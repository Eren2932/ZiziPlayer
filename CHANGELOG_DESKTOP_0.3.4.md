# Desktop 0.3.4 preview

Подготовлено на базе 0.3.3 и мобильных общих компонентов 6.39.9. Это пакет исходников для Windows CI, не проверенный бинарный релиз.

Нижний плеер: собственный тонкий 4dp Slider, круглый hover/focus thumb, центр 700dp с дорожкой 606dp на широком окне, Play32, обложка56, компактная громкость/mute, панель гарнитуры. Таймер изолирован в SeekBar, проверка поколения перемотки сохранена и усилена.

Панели: единый DesktopDock, устранён код подмены закрывающейся очереди эквалайзером; убраны конкурирующие анимации ширины. Геометрия переключается атомарно. Сохраняются вкладки/прокрутка, предыдущий режим левой панели.

Коллекции: обложка232, hero316, Play56, заголовок до96 с измерением текста, соседние Play/Shuffle; строки40/56dp. Артист получил первый блок из пяти треков и правую колонку локальной медиатеки. Градиент принадлежит всей прокручиваемой странице и доходит до первых строк.

Поиск: вкладка «Все», первый результат, треки и полки трёх типов коллекций, жанровые точки входа, собственная медиатека/избранное/история. Существующие endpoints, частичные результаты и отмена; без нового рекомендательного сервера. Длительность каталога читается из dur.

Устройства: реальные Java Sound mixers, выбор выхода в сеансе, существующий handover для seekable трека, системные настройки Windows. Физическое имя default Bluetooth endpoint Java Sound может не раскрывать; Spotify Connect не имитируется.

59 source contracts, Java math/layout, модель контраста и Python connection tests прошли. Восемь новых Kotlin/JUnit tests добавлены, но не запущены. Kotlin/Compose compilation, Windows render и audio-device acceptance требуют Actions и Windows. Полный pixel-perfect/безбаговость не заявляются.
