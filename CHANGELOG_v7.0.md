ZiziPlayer v7.0.0
Тема релиза: цвет плеера действительно повторяет обложку, списки повторяют геометрию
референса, и всё это едет плавно на библиотеке из 3000+ треков.
Метрики сняты пиксельно со скриншотов, не на глаз. Скриншоты — 576 px копии 1080 px экрана;
наш собственный ряд в 62 dp занимает в них 99 px, что калибрует масштаб как 1 px = 0.625 dp.
1. Плеер: фон из обложки, а не тонированный серый
Было (v6.1): 3 цвета обложки, 5 стопов, яркость верхнего стопа 0.135, пик 0.235 на 0.80
высоты. Читалось как «тёмно-серый с оттенком», оттенок один на весь экран.
Стало:
ArtSwatches хранит пять оттенков вместо трёх: primary, secondary, deep, light, vivid. Извлекаются из vibrant / light-vibrant / dark-vibrant / muted / light-muted / dark-muted / dominant, maximumColorCount 20 -> 24, площадь анализа 72² -> 96².
Если обложка одноцветная и Palette возвращает одно и то же значение несколько раз, дубликаты детерминированно разводятся по тону (hsvShift), а не сворачивают рампу в один цвет.
Фон — 7 стопов, 5 разных тонов. Позиции и яркости с референса: 0.00 -> 0.050, 0.16 -> 0.115, 0.34 -> 0.160, 0.50 -> 0.195, 0.67 -> 0.240 (пик под кнопками, не под обложкой), 0.83 -> 0.185, 1.00 -> 0.130.
Насыщенность ограничена 0.32 (референс держит 0.26–0.30). Выше — тёплая обложка превращает экран в коричневую грязь.
Свечение — два радиальных слоя: узкий за обложкой (alpha 0.34, было 0.26) и широкий вполсилы под кнопками. Одним радиалом обе зоны не получить без пересвета верха.
Совместимость: pack() пишет формат 2|..., unpack() читает и старые три цвета и новые пять. Индекс v6.1 не сбрасывается — 3000 файлов не переиндексируются заново.
2. Списки: геометрия референса
v6.1	v7.0	референс
шаг ряда, библиотека	62 dp	56 dp	91 px = 56.4 dp
обложка	48 dp	48 dp	76 px = 47.5 dp
шаг ряда, очередь	~64 dp (padding)	56 dp фиксированно	92 px = 56 dp
высота шторки очереди	460 dp	64% экрана	почти во весь экран
Фиксированная высота ряда — это ещё и перформанс: список больше не перемеряет ряд при скролле.
3. Скролл: 400+ треков
Индексация идёт за пальцем. v6.1 обходил библиотеку в файловом порядке: после прыжка на 300-й трек фоновый проход всё ещё щупал ряды 1–40, а видимые обложки оставались пустыми, и каждая такая проба соревновалась со скроллом за те же ядра. Теперь ArtworkPrefetcher берёт окно из 40 рядов от первого видимого (focusOn из библиотеки и из очереди), и только потом добирает остальное — 6 мс между файлами в окне, 24 мс на хвосте.
Декод с диска ограничен семафором на 3. v6.1 гейтил системные декодеры, но не дисковый кэш: быстрый флик по 400 рядам мог запустить 40 параллельных WebP-декодов и выжрать все ядра.
Ряды без обложки больше ничего не запускают. Вердикт «обложки нет» лежит на диске, он читается прямо из композиции — 400 корутин, которые могли вернуть только null, не создаются.
Повторная проверка памяти под каждым семафором: пока ждали пермит, сосед мог уже декодировать.
Эквалайзер на играющем ряду больше не аллоцирует список и три боксированных float 60 раз в секунду.
Подключён profileinstaller — первый скролл не идёт интерпретатором.
4. Шторки: свои, быстрые
ModalBottomSheet заменён на собственный ZiziSheetScaffold в Popup:
открытие — пружина damping 0.85 / stiffness 1600 (~180 мс, без овершута), закрытие 150 мс;
ни одного чтения анимируемого значения в композиции: сдвиг — graphicsLayer.translationY, затемнение — alpha слоя. Вся анимация проходит без единой рекомпозиции;
свайп вниз закрывает (порог 26% высоты или скорость 900), тап по затемнению и «назад» тоже;
Popup = своё окно, поэтому шторку можно вызывать из любого места, включая Column, и она не отбирает место у экрана под ней.
5. Настройки: по полочкам
Порядок групп: Воспроизведение -> Оформление -> Библиотека -> Данные -> О приложении.
«Пропускать тишину» переехало из «Звука» наверх, в «Воспроизведение».
Сортировка — полоса чипов вместо раскрывающегося списка. Было: тап, прыжок layout, пять новых строк, второй тап. Стало: один тап, ничего не прыгает.
Новая группа «Данные»: размер кэша обложек (считается на IO, не в композиции) и очистка по тапу. Очистка сбрасывает и память, и вердикты префетчера.
6. Избранное, плейлисты, папки
Общая панель действий над списком: счётчик с правильной формой слова
(1 трек / 2 трека / 5 треков), «Перемешать» и «Играть всё». Раньше перемешать можно было
только всю библиотеку, из-за чего «Избранное» было тупиком.

ui/components/Artwork.kt — 5 оттенков, версионированный формат, семафор на диск, окно префетча, cacheBytes / clearCache, быстрый путь для рядов без обложки
ui/theme/ZiziTheme.kt — 7 стопов, 5 тонов, калиброванная рампа, второй радиал
ui/screens/LibraryScreen.kt — 56 dp ряд, focusOn, панель действий
ui/screens/Sheets.kt — свой Popup-лист, очередь 56 dp / 64% экрана, настройки по полочкам
ui/components/Common.kt — эквалайзер без аллокаций в кадре
MainActivity.kt — свечение 0.26 -> 0.34, центр 0.30 -> 0.28
